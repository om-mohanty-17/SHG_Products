# 🛍️ SHG Products – E-Commerce Website  
### *Empowering Self-Help Groups *

---

## 🌱 Introduction

The **SHG Products E-Commerce Website** is a **frontend-only web application** developed to showcase products created by **Self-Help Groups (SHGs)** 

The platform aims to bridge the gap between **rural artisans and consumers** by providing a clean, responsive, and user-friendly digital marketplace.

---



## 🧩 About the Website

The website acts as a **digital storefront** for SHG-made products such as handicrafts, textiles, food items, and wellness products.

Users can:
- Browse products
- View product details
- Add/remove items from cart
- Manage quantities
- View order summary  
*(No backend or payment gateway integration is used)*

---

## ⭐ Key Features

### 🏠 Homepage
- Introduction to SHGs and UBA
- Hero section with impact messaging
- Featured products
- Social impact highlights

### 🛍️ Product Management
- Product listing with images, names, categories, and prices
- Product detail modal popup
- Category-based filtering
- Price-based filtering
- Sorting (price & name)
- Product search functionality 🔍

### 🛒 Cart & Order Summary
- Add and remove products
- Quantity increment / decrement
- Dynamic price calculation
- Cart count badge
- Tax and shipping calculation
- Promo code support 🎟️

### 💾 Data Persistence
- Cart data stored using **Browser LocalStorage**
- Cart remains intact on page reload

### ✅ Checkout Simulation
- Checkout confirmation modal
- Order summary display
- Success message supporting SHGs 💚

---

## 🎨 Design Approach

The design follows an **earthy, organic theme** inspired by rural craftsmanship and sustainability.

**Design principles used:**
- Clean and readable typography
- Earth-tone color palette
- Card-based layout
- Responsive design for mobile and desktop 📱💻
- Consistent spacing and alignment

---

## 🧰 Tech Stack Used

| Layer | Technology |
|-----|-----------|
| 🌐 Markup | HTML5 |
| 🎨 Styling | CSS3 (Custom + Responsive Design) |
| ⚙️ Logic | JavaScript (ES6) |
| 💾 Storage | Browser LocalStorage |
| 📐 Layout | CSS Grid & Flexbox |
